# DickCraftTg

Telegram-игра для групп на Python 3.10+. На Windows дополнительно установите базу часовых поясов: `py -m pip install tzdata`. На Linux обычно используется системная база часовых поясов.

## Запуск

1. Создайте бота в @BotFather. Сохраните токен в защищённой переменной окружения `BOT_TOKEN`, не в Git и не в чате.
2. В @BotFather выполните `/setprivacy` → выберите бота → Disable. Затем удалите и заново добавьте бота в группу. Это нужно для распознавания кириллических команд: Telegram не считает их стандартными bot commands. Боту не нужны права администратора. После отключения privacy бот получает обычные сообщения; код обрабатывает только команды.
3. Из корня репозитория запустите `python3 bot.py`. Используется long polling; публичный сервер и входящий порт не нужны. Запускайте только один экземпляр на токен. Нужен HTTPS-доступ к `api.telegram.org`.
4. В группе отправьте `/писюн`, повторите команду для проверки дневного ограничения, затем `/мой_писюн`, `/топ`, `/чат`.

Необязательные настройки:

- `DB_PATH`: путь SQLite, по умолчанию `data/game.sqlite3`. Сохраняйте базу между перезапусками; для резервного копирования используйте SQLite backup API или останавливайте бота и копируйте все файлы базы вместе с WAL.
- `GAME_TIMEZONE`: часовой пояс IANA, по умолчанию `Europe/Moscow`.

## Правила

Каждая пара «участник + беседа» начинает с 0 см. `/писюн` один раз за календарный день выбирает рост с вероятностью 70% или уменьшение с вероятностью 30%; величина изменения — от 1 до 10 см. Допускаются отрицательные значения. `/мой_писюн` показывает результат. `/топ` выводит 10 игроков, `/топ_все` — всех игравших в беседе (длинный список разбивается на сообщения). `/чат` суммирует их длины. `/ролл` выдаёт число 1–100 без дневного лимита.

Рейтинг включает только игравших, а не всех участников Telegram-группы. Бот не удаляет результат при выходе участника. Перенос рейтинга при миграции обычной группы в супергруппу пока не реализован. Общего рейтинга между беседами нет: его команда и правила в предоставленном описании отсутствуют.

## Проверки

```sh
python3 -m unittest discover -s tests -v
```

Проверяются дневной лимит и московская полночь, разделение бесед, рейтинг, сумма, сохранение в SQLite, адресация команд, ролл и разбиение сообщений. Для проверки реального обмена с Telegram требуется токен и группа.

## Кнопки и меню команд

После запуска отправьте `/help` в группе: бот покажет клавиатуру с кириллическими командами. Клавиатура добавляется ко всем ответам; скрытую клавиатуру можно снова открыть кнопкой клавиатуры в Telegram.

При запуске бот удаляет ранее зарегистрированный общий список команд Telegram, чтобы он не появлялся при вводе `/`. Кнопки клавиатуры сохраняются. Латинские варианты `/grow`, `/mine`, `/top`, `/top_all`, `/chat`, `/roll`, `/help` продолжают работать при ручном вводе. Telegram может обновить отображение после повторного открытия чата.
